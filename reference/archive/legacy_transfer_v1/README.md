# Legacy transfer-v1 archive

This directory preserves the superseded eight-vector transfer experiment for
provenance only. In that experiment, `B2` meant **Same-URL Multi-Tenant
Confusion** and `B3` meant **Binding Downgrade / Version Confusion**.

The active CardDiffBench taxonomy has seven vectors. It removes the former
tenant-confusion vector and assigns `B2` to **Binding Downgrade / Version
Confusion**. Nothing in this archive is an active benchmark input or a source
for paper statistics; archived labels must not be remapped or combined with the
new `B2` results.
