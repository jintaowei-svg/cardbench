# CardDiffBench AAAI 2027 Overleaf Package

Upload this ZIP to Overleaf and set `main.tex` as the main file.

Included files:

- `main.tex`: CardDiffBench manuscript using the official AAAI 2027 LaTeX style.
- `aaai2027.sty`: official AAAI 2027 style file from `AuthorKit27.zip`.
- `aaai2027.bst`: official AAAI 2027 BibTeX style.
- `aaai2027.bib`: official sample bibliography file, included for template completeness.
- `ReproducibilityChecklist.tex`: official AAAI reproducibility checklist source.
- `main.pdf`: locally compiled preview.

Notes:

- The manuscript currently contains `TODOCITE` placeholders; replace them with verified citations before submission.
- The paper is in anonymous submission mode via `\usepackage[submission]{aaai2027}`.
- The section structure follows the requested reference-paper outline: Introduction, Background, Threat Model, Framework, Evaluation, Conclusion.
